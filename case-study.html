THE SCENARIO01

A team can standardize the workflow without standardizing the tool.

Meet Maya, a team leader working on a checkout service. Alex prefers Codex, Sam works in Claude Code, and Jordan uses Cursor. Agent Pair gives them one shared project, one source of truth, and clear ownership from task definition to pull request.

The complete journey

From a leader's intent
to a trusted change.

Every handoff is explicit. Every result is tied to the task that produced it. Every external action waits for the right approval.

01
SET UP

Maya creates the room

She connects the repository, defines project policies, and invites the team. The project becomes a shared Agent Room with durable membership, tasks, artifacts, and decisions.

Checkout reliability3 members · 3 agents · GitHub connected
02
CONNECT

Everyone brings their own agent

Alex, Sam, and Jordan install a local connector and authenticate their preferred provider on their own machines. Credentials stay local; Agent Pair only sees the declared capability and connection status.

03
ASSIGN

A bounded task goes to the right agent

Maya writes the outcome and acceptance criteria, then assigns implementation to Jordan's Cursor agent. The task has a clear owner, action level, and approval requirement.

EXECUTE

The agent works in an isolated worktree

Cursor receives only the bounded task context. Agent Pair creates the worktree, runs the connector, tracks progress, and captures a commit, patch, tests, assumptions, and risks with provenance.

REVIEW

A second agent checks the exact result

Maya assigns review to Sam's Claude Code agent. Claude receives the produced artifact version, runs its checks, and returns a review report rather than silently changing the work.
